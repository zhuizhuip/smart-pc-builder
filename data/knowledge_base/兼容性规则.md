# 配件兼容性规则

装机最重要的是各配件之间相互兼容，以下是核心兼容规则。

## CPU 与主板

- Intel LGA1700 接口 CPU（12/13/14 代）搭配 B660/B760/Z690/Z790 芯片组主板。
- Intel LGA1851 接口 CPU（酷睿 Ultra 200 系列）搭配 B860/Z890 芯片组主板。
- AMD AM4 接口 CPU（锐龙 5000 系列）搭配 B550/A520/X570 芯片组主板。
- AMD AM5 接口 CPU（锐龙 7000/9000 系列）搭配 B650/A620/X670/X870 芯片组主板。

## 内存与主板

- DDR4 内存只能插 DDR4 主板，DDR5 内存只能插 DDR5 主板，二者不通用。
- Intel 12/13/14 代部分主板支持 DDR4 或 DDR5（同一主板通常只支持其中一种）。
- AMD AM5 平台全面转向 DDR5，AM4 平台使用 DDR4。

## 主板与机箱

- ATX 主板需装进 ATX 或更大机箱；M-ATX 主板可装进 M-ATX 或 ATX 机箱；ITX 主板需 ITX 机箱。
- 装机前确认机箱支持的主板板型列表。

## 显卡与电源

- 电源额定功率需满足显卡要求。中端显卡建议 650W 电源，高端显卡建议 750W 及以上。
- 显卡供电接口（如 8pin、12VHPWR）需与电源提供的线材匹配，或用官方转接线。

## 散热器与机箱

- 风冷散热器高度不得超过机箱 CPU 散热器限高。
- 水冷冷排尺寸（240/280/360）需与机箱支持的冷排位匹配。

## 常见搭配示例

- 锐龙 7500F（AM5）+ B650 主板 + DDR5 内存：主流游戏性价比方案。
- 酷睿 i5-12400F（LGA1700）+ B760 主板 + DDR4/DDR5 内存：主流办公与游戏方案。
- 锐龙 7 7800X3D（AM5）+ X670/B650 主板 + DDR5：高端游戏方案。
