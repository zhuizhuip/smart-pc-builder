# 装机基础与配件选购

## CPU（处理器）

- Intel 与 AMD 是两大主流品牌。Intel 酷睿系列常见型号有 i3/i5/i7/i9，AMD 锐龙系列常见型号有 R5/R7/R9。
- 游戏场景通常更看重单核性能，办公与多任务场景更看重多核性能。
- AMD 锐龙 7000/9000 系列采用 AM5 接口，锐龙 5000 系列采用 AM4 接口；Intel 12/13/14 代采用 LGA1700 接口，酷睿 Ultra 200 系列采用 LGA1851 接口。
- 带核显的 CPU（如 Intel 非 F 后缀、AMD G 后缀）可以在不装独立显卡的情况下点亮主机，适合办公与轻度使用。

## 显卡（GPU）

- NVIDIA 与 AMD 是两大主流显卡品牌。NVIDIA 常见系列有 RTX 50/40/30 系列，AMD 常见系列有 RX 7000/9000 系列。
- 显存容量影响高分辨率游戏与 AI 创作，常见容量有 8GB、12GB、16GB、24GB。
- 游戏显卡选择一般按目标分辨率和游戏类型：1080P 主流网游可选入门级，2K/4K 3A 大作需要中高端显卡。
- 办公与纯文档场景通常不需要独立显卡，用带核显的 CPU 即可。

## 内存（RAM）

- 内存分为 DDR4 与 DDR5 两代，二者插槽不通用，需与主板匹配。
- 主流容量：办公 16GB 起步，游戏 32GB 起步，设计与视频剪辑建议 32GB 及以上。
- 内存频率越高性能越好，但需主板与 CPU 支持，Intel 平台还受 XMP、AMD 平台受 EXPO 支持影响。

## 主板（Motherboard）

- 主板按尺寸分为 ATX、M-ATX、ITX 等板型，需与机箱匹配。
- 芯片组决定主板支持的 CPU 代际与接口，例如 Intel B760/Z790 支持 LGA1700，AMD B650/X670 支持 AM5。
- 供电规模影响 CPU 性能释放，高端 CPU 建议搭配供电较强的主板。

## 固态硬盘（SSD）

- 固态硬盘分为 NVMe（走 PCIe 通道，速度快）与 SATA（走 SATA 通道，速度较慢）。
- 主流容量：系统盘 512GB 起步，游戏与素材存储建议 1TB 及以上。
- 读写速度影响系统启动与游戏加载速度，NVMe 是当前装机首选。

## 电源（PSU）

- 电源额定功率需大于整机满载功耗，并预留一定余量，常见额定功率有 550W、650W、750W、850W、1000W。
- 80PLUS 认证等级（白牌/铜牌/金牌/白金牌）代表转换效率，金牌及以上更省电稳定。
- 显卡是功耗大头，选电源时先确认显卡官方推荐功率。

## 散热器（Cooler）

- 散热器分为风冷与水冷。风冷结构简单、寿命长；水冷散热上限更高，常见 240/360 冷排。
- 高功耗 CPU（如旗舰型号）建议搭配更强散热，普通 CPU 用百元级风冷即可。
- 散热器高度需与机箱限高匹配，水冷冷排尺寸需与机箱支持位置匹配。

## 机箱（Case）

- 机箱按板型支持分为 ATX 机箱、M-ATX 机箱、ITX 机箱，需与主板板型匹配。
- 机箱需考虑显卡限长、散热器限高、硬盘位数量与风道设计。
