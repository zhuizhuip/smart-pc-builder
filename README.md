# 毕业设计 · 淘宝数据采集指南

本仓库提供使用 **Selenium** 对淘宝搜索页面进行**浏览器自动化 + 页面下载**的入门模板，供毕业设计数据采集学习使用。

> ⚠️ **合规声明**：请遵守淘宝《用户服务协议》与 robots.txt，仅采集公开展示信息，不用于商业销售，不绕过技术保护措施。采集频率须合理，不对服务器造成负担。

---

## 快速开始

### 1. 安装依赖

```bash
pip install selenium
```

Selenium 4+ 内置驱动管理，无需单独下载 ChromeDriver；但本机需安装 **Google Chrome**。

### 2. 运行爬虫脚本

```bash
python taobao_selenium_crawler.py
```

脚本会自动打开 Chrome 浏览器，按照提示操作即可。

---

## 操作流程说明

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 程序打开淘宝首页 | 浏览器窗口弹出 |
| 2 | **手动扫码/账号登录** | 程序等待你在终端按回车 |
| 3 | 程序输入搜索关键词并跳转 | 等待结果页加载 |
| 4 | 自动滚动页面 | 触发懒加载，加载更多商品 |
| 5 | 保存页面 HTML | 存为本地 `.html` 文件供后续解析 |
| 6 | 尝试提取结构化字段 | 若成功，输出 `.csv` 文件 |

## 推荐采集的数据字段

以下字段适合电商类毕业设计数据集，建议在 CSV 中保留：

| 字段名 | 说明 | 用途示例 |
|--------|------|----------|
| `keyword` | 搜索关键词 | 分组分析、对比不同品类 |
| `crawl_time` | 采集时间（ISO 格式） | 时间序列分析 |
| `page_num` | 当前第几页 | 排名与页面位置分析 |
| `item_id` | 商品 ID（URL 中提取） | 去重、追踪历史变化 |
| `title` | 商品标题 | 文本分析、关键词提取 |
| `price` | 展示价格（字符串） | 价格分布、竞争分析 |
| `shop_name` | 店铺名称 | 商家分析 |
| `location` | 发货地 | 地理分布分析 |
| `sales_text` | 销量文本（如"月销1000件"） | 销量参考指标 |
| `item_url` | 商品详情页链接 | 后续深度采集 |
| `is_ad` | 是否为广告位（0/1） | 过滤广告干扰 |
| `label` | 自定义标签 | 人工标注、分类任务 |

> 💡 **提示**：`price`、`sales_text` 在淘宝页面中常以图片或特殊标签展示，采集时需灵活处理，建议先保存原始 HTML，再离线解析。

## 选择器维护说明

淘宝页面结构和 CSS 类名**经常更新**，脚本中的选择器可能随时失效。维护方法：

1. 用 Chrome 打开目标页面
2. 按 `F12` 打开开发者工具
3. 点击"元素选择"按钮（左上角箭头图标）
4. 点击页面中的目标元素（如商品标题）
5. 在 Elements 面板查看 HTML 结构，复制对应的 CSS 选择器

脚本已对每个字段的提取加了 `try/except`，单个字段失败不会中断整体流程。

## 常见问题

**Q：搜索后被跳转到登录页怎么办？**  
A：在"手动登录"步骤完成登录后再按回车，脚本会等待你完成。

**Q：提取的数据很少或为空怎么办？**  
A：先查看保存的 HTML 文件确认内容存在，再用开发者工具重新核对 CSS 选择器。

**Q：程序报 `NoSuchElementException` 怎么办？**  
A：淘宝选择器已更新，需要重新检查。查看 `driver.page_source[:3000]` 了解当前结构。

**Q：可以不登录吗？**  
A：淘宝在未登录状态下会限制搜索结果展示，建议登录后采集以获取完整数据。
